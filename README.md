# NE 2026 Map Export

Auto-generated Guru Maps overlay (GeoJSON + MapCSS) for a New England road trip. `map.geojson` holds whichever day's points of interest were last exported; `map.mapcss` styles them by icon/color. Regenerated on request via `export_day.py`, which reads from a private trip-planning vault.

Import `map.ms` into Guru Maps once — after that it auto-refreshes from this repo.
